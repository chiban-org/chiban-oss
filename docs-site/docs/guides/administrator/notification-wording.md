# Wording of emails

Chiban emails applicants, staff, reviewers and boards when an application is received, a fee is due, a permit is issued, an inspection is booked, a deadline is near and in other cases. Open **Settings**, then **Notification wording** to change what each message says. They are grouped by who gets them.

- **To applicants and contractors**: Application received, Fees due, Payment received, Permit issued, Application denied, Inspection scheduled, Inspection cancelled, Inspection result, Permit corrected, Permit corrected with the contractor removed, and Board decision filed.
- **To staff**: Deadline coming up and Deadline passed.
- **To reviewers**: Review requested.
- **To boards**: Board comments requested.

## Edit a message

1. Choose the message from the list. It opens with the **Standard wording**.
2. Change the **Subject** and the **Message**. Leave a blank line between paragraphs.
3. To add a detail, select a field under **Fields this message can use**. It goes in at the cursor. For the application received message these are the application number, the applicant's name, the town name and the link.
4. Read the result under **Preview with sample details**, which fills in a sample application.
5. Choose **Save draft** or **Put into use**. See [how changes are saved and put into use](./how-changes-are-put-into-use.md).

Chiban adds the link at the end of the message unless you place the Link field yourself. It leaves out a whole paragraph when none of the fields in it has a value, so an optional detail does not leave an empty line behind.

**Reset to the standard wording** goes back to what Chiban shipped.

## Links and the permit itself

The link in each message opens the application. The wording of the permit itself is changed under [forms, fee schedules and letters](./forms-fee-schedules-and-letters.md).

The demo does not allow edits here, and it does not deliver mail.
