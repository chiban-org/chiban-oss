# Wording of emails

Chiban sends email when an application is received, a fee is due, a permit is issued, an inspection is booked, a board packet is ready, a records request comes in and in other cases. Open **Settings**, then **Notification wording** to change what each message says. The messages are grouped by who gets them.

- **To applicants and contractors**: Application received, Fees due, Payment received, Permit issued, Application denied, Inspection scheduled, Inspection cancelled, Inspection result, Permit corrected, Permit corrected with the contractor removed, Board decision filed, and Claim a project.
- **To staff**: Deadline coming up and Deadline passed.
- **To reviewers**: Review requested.
- **To boards**: Board comments requested, Added to a board, Board packet ready, Board packet ready by link, Board packet updated, and Meeting cancelled.
- **To records requesters**: Records request received, Letter about a records request, Records ready by link, and Records attached.

Sign-in links, password resets and new staff account emails keep fixed wording, and so do health alerts and scheduled report emails.

## Edit a message

1. Choose the message from the list. It opens with the **Standard wording**.
2. Change the **Subject** and the **Message**. Leave a blank line between paragraphs.
3. To add a detail, select a field under **Fields this message can use**. It goes in at the cursor. Each message offers only the fields it has. The application received message, for example, offers the application number, the applicant's name, the town name and the link. The records request received message offers the request number, the date it came in and the date the town will answer by.
4. Read the result under **Preview with sample details**, which fills in sample values.
5. Choose **Save draft** or **Put into use**. See [how changes are saved and put into use](./how-changes-are-put-into-use.md).

Chiban leaves out a whole paragraph when none of the fields in it has a value, so an optional detail does not leave an empty line behind.

**Reset to the standard wording** goes back to what Chiban shipped.

## Fields a message must keep

A few messages will not save without certain fields:

- **Records request received** must include the request number and the date the town will answer by. The receipt is the requester's written record of both.
- **Records ready by link**, **Board packet ready by link** and **Claim a project** must include the number of days the link works, so the reader knows when it stops working.

## Links

Most messages carry a link: to the application, to the board pages, or to a one-time link for a packet, a project claim or released records. Chiban adds the link at the end of the message unless you place the Link field yourself. You cannot type a web address into a message.

Three messages have no link, and their editor says so: **Meeting cancelled**, **Letter about a records request** (the letter is attached) and **Records attached** (the records are attached). **Board packet updated** carries the board pages link only for members who sign in. A reader who got the packet by link is told to use the link from the earlier email.

The wording of the permit, the records letters and other documents is changed under [forms, fee schedules and letters](./forms-fee-schedules-and-letters.md).

The demo does not allow edits here, and it does not deliver mail.
